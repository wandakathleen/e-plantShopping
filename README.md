# Paradise Nursery Shopping Application (`e-plantShopping`)

Welcome to **Paradise Nursery**, an interactive, responsive front-end e-commerce web application developed with React, Redux Toolkit, and Vite.

## Project Overview
Paradise Nursery offers a curated selection of house plants categorized by specific home benefits: Air Purifying, Aromatic, and Medicinal plants. This application provides a multi-view shopping experience featuring dynamic cart calculations, state management, and real-time UI updates.

## Features
- **Interactive Landing Page:** Engaging company background, mission statement, and direct entry into the shopping catalog.
- **Categorized Product Catalog:** Browse 18 unique plants divided across 3 specialized categories, complete with thumbnail previews, descriptions, and unit prices.
- **Global Cart Management:** Centralized Redux state management using Redux Toolkit slices (`addItem`, `removeItem`, `updateQuantity`).
- **Dynamic Quantity Tracking:** Header navbar reflects the exact aggregate quantity of plants in real time.
- **Shopping Cart Review:** Real-time item subtotal calculation, order total summation, item increment/decrement adjustments, item deletion, and checkout alert prompts.

## Tech Stack
- React 18 (Functional Components, Hooks)
- Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
- Vite Build Tool
- CSS3 & Modern Responsive Design
